## 🚀 Comandos para subir a GitHub

### Después de crear el repositorio en GitHub, ejecuta:

```bash
# Agregar el repositorio remoto (REEMPLAZA LA URL POR LA TUYA)
git remote add origin https://github.com/TUSUARIO/biblioteca-gamer-backend.git

# Subir el código a GitHub
git branch -M main
git push -u origin main
```

### Si Git te pide credenciales:
- **Usuario:** tu usuario de GitHub
- **Contraseña:** tu Personal Access Token (no la contraseña normal)

### Para crear un Personal Access Token:
1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Generate new token → Selecciona 'repo' → Generate token
3. Copia el token y úsalo como contraseña
